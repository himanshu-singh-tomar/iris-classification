
# Executive Summary: Iris Flower Classification

**Project:** Iris Flower Classification  
**Internship:** Alfido Tech — Machine Learning

## Objective
The objective of this project was to develop a machine learning model that predicts iris flower species from sepal and petal measurements.

## Dataset
The dataset originally contained 150 records and five columns: four numerical measurement features and one target column, species. Three duplicate rows were removed, leaving 147 records for analysis.

## Methodology
The project included data inspection, duplicate handling, exploratory data analysis, an 80:20 train-test split, and training three classification algorithms:
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree

## Results
Test accuracy:
- Logistic Regression: 96.67%
- K-Nearest Neighbors: 100.00%
- Decision Tree: 93.33%

The final model was selected using the evaluation results, including macro F1-score and accuracy.

**Selected model:** K-Nearest Neighbors

**Macro F1-score:** 1.0000

## Conclusion
The project demonstrates an end-to-end classification workflow, including data preparation, visualization, model comparison, evaluation, model saving, and prediction on a new flower sample.
